## ملاحظة تقنية

- تم ترقية الإصدارات إلى الأحدث المتوافقة مع بعضها:
  Next.js 16.2، React 19، Tailwind CSS v4 (إعداد CSS-first عبر `@theme`)،
  TypeScript 5.9، ESLint 9 (flat config).
- TypeScript 7 وESLint 10 غير مدعومين بعد من `typescript-eslint`/`eslint-config-next`.
- Tailwind v4: لا يوجد `tailwind.config.ts` — التوكينات في `app/globals.css` عبر `@theme`.
- الاتصال الحالي بـ Supabase يعتمد على `@supabase/supabase-js` + `@supabase/ssr` مع
  browser client للعمليات العامة وread client على السيرفر.
