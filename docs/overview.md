# دليل الصنايعية — نظرة عامة

## الفكرة
منصة ويب محلية بسيطة تعرض قائمة حرفيين (سباكين، كهربائيين، نجارين...) في
مدينة السويس، بدون أي تسجيل دخول. أي زائر يدخل الموقع يلاقي الحرفي المناسب
ويكلمه مباشرة (اتصال أو واتساب) في أقل عدد خطوات ممكن.

## الهدف
تقليل الوقت والخطوات اللي بياخدها الشخص عشان يلاقي حرفي موثوق في منطقته:

1. يفتح الموقع.
2. يختار التخصص.
3. يختار حرفي (ممكن يفلتر بالمنطقة).
4. يضغط "اتصال" أو "واتساب" — خلاص.

## المستخدم المستهدف
- سكان مدينة السويس اللي محتاجين حرفي بأقرب وقت.
- أصحاب الأعمال اليدوية (الصنايعية) اللي عايزين يوصّلوا لزبائن أقرب منهم.
- الجهاز الأساسي: **الموبايل** — لذلك الموقع Mobile-first بالكامل.

## الحدود الحالية (مرحلة MVP)
- لا يوجد تسجيل دخول أو حساب مستخدم إطلاقاً.
- البيانات ثابتة في `lib/craftsmen.ts` (ملف JSON/TypeScript) حتى يتم ربطها
  بـ Supabase لاحقاً.
- صفحة التسجيل `/join` لا ترسل بيانات لأي خادم حقيقي بعد — فقط `console.log`
  مع رسالة نجاح وهمية.

## كيف يتوسع لاحقاً
- استبدال مصدر البيانات في `lib/` بـ Supabase بدون تغيير الكومبوننتس
  (الكومبوننتس تعتمد على hooks فقط).
- إضافة بيانات حقيقية للحرفيين والتخصصات النهائية.
- النشر على Vercel من GitHub.
