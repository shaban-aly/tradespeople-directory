# دليل الصنايعية — نظرة عامة

## الفكرة

منصة ويب محلية بسيطة تعرض قائمة صنايعية (سباكين، كهربائيين، نجارين...) في
مدينة السويس، بدون أي حساب للمستخدم العادي. أي زائر يدخل الموقع يلاقي الصنايعي
المناسب ويكلمه مباشرة (اتصال أو واتساب) في أقل عدد خطوات ممكن.

## الهدف

تقليل الوقت والخطوات اللي بياخدها الشخص عشان يلاقي صنايعي موثوق في منطقته:

1. يفتح الموقع.
2. يختار التخصص.
3. يختار صنايعي (ممكن يفلتر بالمنطقة).
4. يضغط "اتصال" أو "واتساب" — خلاص.

## المستخدم المستهدف

- سكان مدينة السويس اللي محتاجين صنايعي بأقرب وقت.
- أصحاب الأعمال اليدوية (الصنايعية) اللي عايزين يوصّلوا لزبائن أقرب منهم.
- الجهاز الأساسي: **الموبايل** — لذلك الموقع Mobile-first بالكامل.

## الحالة الحالية (MVP)

- البيانات الآن من **Supabase**: تصنيفات، مناطق، صنايعية، وروابط السوشيال.
- الصفحة العامة ما زالت بدون تسجيل دخول للمستخدمين العاديين.
- صفحة التسجيل `/join` ترفع الصورة إلى Supabase Storage بعد تحويلها إلى WebP،
  ثم ترسل الطلب إلى جدول `join_requests` للمراجعة.
- توجد لوحة تحكم مشرف على `/admin` لتسجيل الدخول، مراجعة الطلبات، وإدارة
  التخصصات والمناطق والصنايعية.

## كيف يتوسع لاحقاً

- تحسين لوحة التحكم بإمكانيات تعديل أوسع وإدارة الصور والسوشيال.
- إضافة بيانات حقيقية أكثر وتحديثها باستمرار من خلال لوحة الإدارة.
- إضافة حماية Server أقوى لمسارات الإدارة.
- النشر على Vercel من GitHub.
